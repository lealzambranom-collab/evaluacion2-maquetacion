## ¿Qué hace este proyecto?

Es un catálogo web dinámico para la panadería y repostería **Horno de la Abuela** en el que las tarjetas de los 12 productos se generan con JavaScript a partir de `js/datos.js` y se pueden filtrar por categoría (`Todas`, `Panes`, `Tortas`, `Galletas`, `Bebidas`), buscar por nombre o descripción en tiempo real y ordenar por nombre o precio.

El diseño aplica el Manual de marca de la empresa sobre Bootstrap 5.3 usando variables CSS (`#8a4b20`, `#e8b04b`, `#fffaf2`, `#33241a`), tipografías de Google Fonts (`Fredoka` y `Open Sans`) y criterios de accesibilidad web.
